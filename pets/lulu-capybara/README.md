# 水豚噜噜 v2

Codex 桌宠完整 v2 动作包。噜噜采用黄色圆胖 3D 玩偶造型，拥有光滑的橙色嘴部、圆眼、小耳朵、头顶小橘子和橙色短裤；角色没有鼻孔。

## 内容

- `pet.json`：Codex 桌宠清单，版本号为 2
- `spritesheet.webp`：1536 × 2288 的透明背景 v2 图集
- `index.html`：全部动作的在线预览
- `lulu-capybara-v2.zip`：可下载的安装包

动作包括慢眨眼、左右走动、挥手、小跳、委屈、等待回应、思考、查看结果，以及 16 个方向姿态。

## 安装

解压下载包，将其中的 `lulu-capybara` 文件夹放入 Codex 的自定义桌宠目录：

```text
~/.codex/pets/lulu-capybara
```

完全退出并重新打开 Codex，然后选择“水豚噜噜”。

## 校验

- Codex sprite version：2
- 图集：8 列 × 11 行
- 单格：192 × 208
- 图集尺寸：1536 × 2288
- 透明背景与有效动作格均已校验
