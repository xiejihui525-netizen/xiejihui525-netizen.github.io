# Jessie Xie Personal Homepage

This folder contains a static single-page personal homepage for Jessie Xie.

## Files

- `index.html`: Homepage content and structure.
- `styles.css`: Responsive visual styling.
- `assets/Jessie-Xie-Resume.pdf`: Latest resume file linked from the page.
- `assets/profile.jpg`: Jessie Xie's resume photo used as the homepage profile image.
- `assets/resume-photo-wide.jpeg`: Resume photo asset.
- `assets/resume-photo-id.jpeg`: One-inch resume photo asset.
- `assets/professional-photo.jpg`: Professional image photo kept as a backup asset.

## Preview

Open `index.html` in a browser to preview the homepage locally.

## GitHub Pages

To publish with GitHub Pages, upload the contents of this folder to a GitHub repository and set GitHub Pages to serve from the repository root or from this folder, depending on your repository setup.

## Privacy

The homepage only exposes the email address listed in the plan. Phone and WeChat details are intentionally not shown.
